# Panel plemienia

Panel do Plemion: przegląd graczy, wojska i budynków, obstawy, selekcja oraz tabelki na mapie.

## Instalacja

### [Kliknij tutaj, żeby zainstalować panel](https://raw.githubusercontent.com/BartoszWiszniewski/plemiona-panel/main/efekt_panel_plemienia.user.js)

1. Zainstaluj dodatek Tampermonkey: [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo), [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/), [Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd).
2. Tylko Chrome i Edge: wejdź w szczegóły dodatku Tampermonkey (`chrome://extensions`) i włącz **Zezwalaj na skrypty użytkownika**. Jeśli nie ma tej opcji, włącz **Tryb dewelopera** w prawym górnym rogu tej strony.
3. Kliknij link powyżej i potwierdź **Zainstaluj**.
4. Odśwież grę. Przycisk **Panel plemienia** jest w prawym dolnym rogu na mapie i na stronach plemienia.

Aktualizacje przychodzą same przez Tampermonkey. Dane panelu zostają w przeglądarce i nigdzie nie są wysyłane.
